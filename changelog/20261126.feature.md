Bump bundled OPNsense API registry from 26.7.9 to 26.7.10.

Regenerated `controllers.json` (93 modules / 300 controllers / 2042 actions,
+1 controller, net +4 actions) and `models.json` (54 modules / 104 models)
from upstream `opnsense/core` and `opnsense/plugins` at tag 26.7.10
via `tools/generate_all.py`, plus pinned-version references (`spec_version`,
Makefile, docs).

Notable upstream API changes in range: new `auth/userapikey` controller
(search/get/set/del) backed by a new `Auth/ApiKey` model — API keys move out
of `auth/user` (whose legacy `searchApiKey`/`addApiKey`/`delApiKey` actions
are marked for removal in 27.1); ddclient `dyndns` gains `ionos-v4`/`ionos-v6`
providers; routing gateway latency/loss `ComparedToFieldConstraint`s dropped.
The new `auth/userapikey` controller has no reconfigure endpoint, so the
generic state skips the apply step for it
(`states/opnsense._NO_RECONFIGURE_CONTROLLERS`).
